# Voice lines

Record these short lines in your own voice (or a friend's) and save them as **.mp3** files in the right folder.
The game plays them automatically. If a file is missing, the game plays a beep instead, so you can add them one by one.

Tip: record on your phone in a quiet room, keep each line short (under 2 seconds), and convert to mp3 with any free converter.

| File name     | When it plays          | English (`en/`)        | Tigrinya (`ti/`)           | Amharic (`am/`)          |
|---------------|------------------------|------------------------|----------------------------|--------------------------|
| `count3.mp3`  | Race countdown         | Three                  | ሰለስተ                       | ሶስት                      |
| `count2.mp3`  | Race countdown         | Two                    | ክልተ                        | ሁለት                      |
| `count1.mp3`  | Race countdown         | One                    | ሓደ                         | አንድ                      |
| `go.mp3`      | Race / taxi starts     | Go!                    | ጀምር!                       | ጀምር!                     |
| `pickup.mp3`  | Taxi: passenger gets in| Passenger on board     | ተሳፋሪ ደዪቡ                   | ተሳፋሪ ገብቷል                |
| `fare.mp3`    | Taxi: passenger dropped| Delivered! Plus twelve seconds | ኣብጺሕካዮ! 12 ካልኢት ተወሰኸ | አደረስክ! 12 ሰከንድ ተጨመረ |
| `lap.mp3`     | Start of the last lap  | Last lap!              | ናይ መወዳእታ ዙር!              | የመጨረሻ ዙር!                |
| `win.mp3`     | You finish 1st         | You win!               | ተዓዊትካ!                     | አሸነፍክ!                   |
| `finish.mp3`  | Race / shift ends      | Finished               | ወዲእካ                       | ጨርሰሃል                    |

Change the wording to how people really speak at home. These are only suggestions.

Folder layout:

```
voice/
  en/count3.mp3 ...
  ti/count3.mp3 ...
  am/count3.mp3 ...
```
