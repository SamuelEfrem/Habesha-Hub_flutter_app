# Driving test – instructor voice

Record each line as its own **.mp3** and put it in `voice/<language>/`, named exactly as in the first column.
The game plays a recorded line when **all** the lines it needs at that moment exist; otherwise the phone voice reads the text.
Start with Tigrinya (`ti/`) – phones have no Tigrinya voice.
